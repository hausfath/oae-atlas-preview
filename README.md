# OAE Supply-Chain Atlas: temporary internal preview

A temporary preview of Frontier's ocean alkalinity enhancement (ocean liming) supply-chain map,
shared for colleague feedback. **Internal to Frontier; not for redistribution.** It includes data
that is not cleared for publication (IEAGHG/OGCI CO2 Storage Resource Catalogue sites, GLiM- and
WDPA-derived layers, IMF PortWatch fields, and Frontier TEA calibration). This repository will be
deleted after the feedback round. The model, pipeline and methods live in a separate repository.
